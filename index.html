Hướng dẫn sử dụng

Công cụ mô phỏng chiếu sáng đường theo QCVN 07-7:2023. Mọi tính toán chạy ngay tại máy — file không gửi lên mạng.

1. Chuẩn bị dữ liệu

  • File Excel (sheet DU LIEU TUYEN): mỗi dòng là một phương án đèn của tuyến. Các cột cần có: Độ cao bộ đèn (m), Độ vươn cần đèn (m), Khoảng cách trụ đến mép đường (m), Độ rộng lòng đường (m), Khoảng cách trụ TB (m), Số làn xe, Góc nghiêng bộ đèn (độ), Cách bố trí trụ, Cấp đường, Loại đèn, Công suất LED (W). Dùng file DATA_TUYEN_DEN_LED_SACH.xlsx là đủ chuẩn.
  • Thư mục IES: chứa các file .ies (IESNA LM-63). App tự dò theo thư mục con. Tên file nên có model + công suất (vd …MAGNOLIA…60W…) để khớp đúng.

2. Các bước chạy

  1. Bấm 📄 Chọn file Excel → chọn file dữ liệu tuyến.
  2. Bấm 📁 Chọn thư mục IES → chọn thư mục chứa .ies.
  3. Chỉnh MF (hệ số bảo trì, mặc định 0,8) và Chế độ nếu cần.
  4. Bấm ▶ Chạy → xem bảng kết quả + thẻ tổng hợp (Đạt / Không đạt / Thiếu IES). Lọc hoặc gõ tên tuyến để tìm.
  5. Bấm 💾 Ghi/Tải Excel để ghi kết quả (Ltb/Uo/Ul/TI/SR + Đạt) vào file.
  6. Bấm 📑 Xuất PDF để xuất báo cáo kiểu DIALux (các tuyến đang lọc, 1 trang/tuyến).

3. Hai chế độ tính

  • Từng phương án: tính đúng bộ đèn ghi trên mỗi dòng. Dùng chế độ này để ghi kết quả vào Excel.
  • Tự dò: với mỗi tuyến, tự chọn đèn cùng model có công suất nhỏ nhất vẫn Đạt (tối ưu điện năng).

4. Ghi file & lưu ý

  • Trên Chrome/Edge (GitHub Pages hoặc chạy bằng local server): ghi đè thẳng file .xlsx gốc. File .xlsm sẽ xuất ra file mới để không hỏng macro.
  • Trong khung xem trước có thể bị chặn tải — mở app ở neo-era.github.io/webdialux-cs/ hoặc local là ghi/tải mượt.
  • Dòng "Thiếu IES" = chưa có file .ies khớp model+công suất → bổ sung vào thư mục IES.
  • Độ chói dùng bảng R3 CIE (khớp DIALux cho Ltb & Uo). TI là ước tính, thiên an toàn — dùng tham khảo.
